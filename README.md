# ☕ Brewmaster - Coffee Shop Management System

A modern full-stack application for managing coffee shop orders, inventory and users.

🔗 **Live Demo:** https://brewmaster-ivory.vercel.app

### ✨ Features
- User Authentication (Login / Signup)
- Coffee Menu Management
- Cart & Order System
- Admin Dashboard
- Secure REST API with Django

### 🛠️ Tech Stack
- **Frontend:** Next.js 14, React, Tailwind CSS
- **Backend:** Django, Django REST Framework
- **Database:** SQLite (Dev)
- **Deployment:** Vercel (Frontend + Backend)
- **Version Control:** Git & GitHub
